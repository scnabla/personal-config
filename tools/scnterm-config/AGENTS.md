# 独立配置程序开发原则

源码位于 `personal-config/tools/scnterm-config/`；自动构建定义位于仓库根目录的 `.github/workflows/scnterm-config.yml`。

- 使用简体中文编写说明、界面和开发文档。
- 本项目独立于 ScnTerm，禁止引用终端源码、crate 或构建目录。
- 首版面向 Windows 独立窗口，只允许写入串口配置；其他配置只读。
- Lua 读取使用静态解析，禁止执行配置文件。未支持的表达式保留原文并只读。
- 文件编辑按原文位置替换，保留无关代码、注释、编码和换行。无修改时不写文件。
- 保存必须展示差异、校验、备份并检测外部修改。异常时不破坏原配置。
- 测试使用副本和独立桌面，不改用户日常配置，不抢占键盘鼠标。
- 依赖放在项目虚拟环境，构建产物、截图和日志不提交。
- 完成功能后更新使用和开发文档，区分自动测试、界面验证和实际交付结果。
