# 个人终端配置

Ghostty 和 Windows WezTerm 分别维护完整的配置、字体和背景图片。使用时下载对应目录。

| 终端 | 平台 | 独立目录 | 使用方式 |
| --- | --- | --- | --- |
| Ghostty | Linux | [ghostty/](ghostty/) | 在目录中运行 `bash install.sh` |
| WezTerm | Windows | [wezterm/windows/](wezterm/windows/) | 将配置、字体和图片复制到 `%USERPROFILE%\.config\wezterm\` |

先安装对应的终端程序，再放置配置。覆盖已有配置前先备份，文件放好后重新打开终端。具体说明见各目录的 `README.md`。

各目录均包含常规、粗体、斜体和粗斜体四种 `JetBrainsMono Nerd Font Mono` 字体，版本为 JetBrains Mono 2.304、Nerd Fonts 3.5.1，分别附带 `fonts/OFL.txt`。字体来源为 [Nerd Fonts v3.5.1](https://github.com/ryanoasis/nerd-fonts/tree/v3.5.1/patched-fonts/JetBrainsMono/Ligatures)。

个人服务器地址、用户名和绝对路径仅保存在本机配置中。更新仓库时，保留示例连接信息。
