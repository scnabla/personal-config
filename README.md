# 个人配置与配置工具

| 内容 | 目录 |
| --- | --- |
| Ghostty、WezTerm 和 ScnTerm 的终端配置 | [terminal/](terminal/) |
| ScnTerm 独立 Windows 配置程序 | [tools/scnterm-config/](tools/scnterm-config/) |

配置程序支持编辑串口连接、日志和高亮设置，其余 Lua 配置只读。使用说明、示例、依赖与测试在工具目录中维护，程序不引用终端源码。

Windows 程序可从 [配置程序发布页](https://github.com/scnabla/personal-config/releases/tag/scnterm-config) 下载。普通终端配置修改不会触发配置程序的构建。
